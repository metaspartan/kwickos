## Lever 2: kpkg size (linux, CGO_ENABLED=0, -trimpath -buildvcs=false -ldflags="-s -w -buildid=", go1.27.4)
# bytes            before      after       saved
# amd64         5,222,524   4,411,516   -811,008
# arm64         4,915,324   4,128,892   -786,432
# riscv64       4,587,644   3,866,748   -720,896
# Where the size was (amd64, before): code 2.55 MB, runtime function tables 1.94 MB. Biggest code: runtime 470 KB, kpkg 420 KB,
# klauspost zstd with huff0/fse ~270 KB (encoder ~120 KB, index cache only), net + DNS ~170 KB, regexp + Unicode tables ~110 KB,
# klauspost flate ~92 KB (half of it the gzip writer for dpkg-deb -b), math/big 65 KB, ed25519 ~45 KB, ulikunitz/xz + log ~51 KB,
# encoding/asn1 20 KB, net/url + net/netip + unique ~20 KB. kpkg does not link net/http or crypto/tls (https goes to curl/wget).
# Each change measured alone (amd64 bytes):
#   small socket dialer + stub DNS resolver instead of package net (netdial.go)         -327,680  kept
#   own xz/LZMA2 decoder, ulikunitz/xz dropped (xzdec.go; 1.4-1.7x faster decode)        ~-101,000 kept
#   own fixed-Huffman gzip writer for dpkg-deb -b (gzipenc.go)                            ~-105,000 kept
#   RSA PKCS#1 v1.5 verify with own Montgomery modexp instead of math/big                  -90,112  kept (differential test vs math/big)
#   Alpine RSA public keys parsed by hand instead of encoding/asn1                         -86,016  kept
#   small host parser instead of net/url (pins.go hostOf)                                  -81,920  kept
#   own Valid-Until date parser instead of time.Parse                                      -32,768  kept
#   plain-text index cache (no zstd encoder)                                              -241,664  rejected: lists grow 9.2 -> 47 MB on disk
#   own ed25519 verifier instead of crypto/ed25519                                         ~-57,000  rejected: no hand-written signature code
#   -tags netgo,osusergo,nethttpomithttp2                                                        0  no effect
#   standard-library gzip reader instead of klauspost                                      -61,440  rejected: ~25% slower on Packages.gz
#   no inlining in kpkg's own code (-gcflags=-l)                                          -147,456  rejected: 5-10% slower
# Timing, median ms, kwickos:latest container, 6 CPUs (before / after, two rounds; measured with the plain-text cache variant,
# the kept zstd cache reads at about the old speed for queries):
#   apt update (cold) 2221/2500 -> 1883/2029; apt update (warm) 314/369 -> 271/284
#   install curl+perl+git from cached debs 8663/8128/7993 -> 7670/7205/7272; download-only 2193/2032/1966 -> 1728/2003/1656
# Peak memory: download 300 -> 128 MB, install about 500 -> 320-390 MB. go vet and go test ./... pass before and after.
# Base image with the new kpkg (du -skx /): 7212 -> 6708 KiB.
# Target was -2 MB; reached -0.81 MB. The rest is code kpkg uses (regex search, gzip/xz/zstd/bzip2 .deb members, RSA and
# ed25519 signature checks, archive/tar, fmt, the runtime); UPX-style packing was not considered.

# curl: https://deb.debian.org over HTTP/2, verify=0; self-signed, expired and wrong-host badssl.com certificates rejected;

# git: clone https://github.com/madler/zlib.git, git grep -P, commit; git-http-fetch/-push dispatch to the shared helper.
# python3: ssl (OpenSSL 3.5.9), sqlite3 3.54.1, hashlib.pbkdf2_hmac, lzma, bz2, curses, readline, ctypes, decimal;
#   urllib https to pypi.org; tracebacks show source lines; python3 -m venv + pip install requests pyyaml (musllinux wheels,
#   yaml.CLoader present) + requests.get https.
# nginx: nginx -t; HTTP on :80; with a test certificate: HTTP/2 over TLS 1.3 (TLS_AES_256_GCM_SHA384, group X25519MLKEM768)
#   and TLS 1.2 (ECDHE-ECDSA-AES256-GCM-SHA384) from Alpine's openssl s_client and curl.
# openssh-server: host keys (rsa, ecdsa, ed25519, mldsa44_ed25519) generated by postinst; sshd -t; RSA-3072 key login from
#   Alpine's ssh client: kex mlkem768x25519-sha256, host key ssh-ed25519, chacha20-poly1305.
# Coexistence: kwick-curl + `apt install libcurl4t64` installs Debian's libcurl next to it; `apt install --no-lean curl`
#   removes kwick-curl and installs Debian's curl; kwick-python3 + `apt install python3-yaml` replaces it with Debian's
#   Python 3.13.5 and the module imports from /usr/lib/python3/dist-packages; `apt upgrade -s` keeps the lean builds.
# kpkg: go vet ./... and go test ./... pass (golang:1.25, GOTOOLCHAIN=auto), including the new leanbuilds_test.go.
# Security gate (scripts/cve-check.sh lean section): "none of the 18 pinned upstream versions in config/musl-lean/sources
#   predates a security fix in Alpine's security database". With mbedTLS 3.6.8 it failed (fixes listed for 4.1.1 and 4.1.2),
#   and without the five pinned OpenSSL patches it warned about Alpine's 3.5.9-r1.
