## New in 0.7.0

* **Snapshots**: Btrfs snapshots before and after every software change and every hour, file restore, rollback, and starting a snapshot from the boot menu. [SNAPSHOTS](https://github.com/metaspartan/kwickos/blob/main/docs/SNAPSHOTS.md)
* **Software Update**: KwickOS, app and kernel updates in one place, kernels that start once before becoming the default, automatic updates and a Debian security tracker check. [UPDATES](https://github.com/metaspartan/kwickos/blob/main/docs/UPDATES.md), [KERNELS](https://github.com/metaspartan/kwickos/blob/main/docs/KERNELS.md)
* **App Store**: Flathub, Debian, AI agents, and Arch and the AUR once turned on, with Updates and Installed views.
* **Arch and the AUR** (`kwick-arch`, x86_64): Arch repositories and the AUR in a managed environment, gated by known CVEs, with AUR review. [ARCH](https://github.com/metaspartan/kwickos/blob/main/docs/ARCH.md)
* **Agents**: Claude Code, Codex, Gemini CLI, opencode, oh-my-pi, OpenClaw, Hermes, Cybara and more, pinned, verified and sandboxed, with a keystore and the kwick-mcp server. [AGENTS](https://github.com/metaspartan/kwickos/blob/main/docs/AGENTS.md)
* **Nearby Share**: send files to phones and computers nearby from Files, Quick Look, Capture and the Control Center, compatible with LocalSend. [NEARBY](https://github.com/metaspartan/kwickos/blob/main/docs/NEARBY.md)
* **Shells**: `kwick-shell` switches the terminal shell and prompt preset; `kwick-desktop shell` switches between Plasma, GNOME, Hyprland, Sway, Quickshell, Dux Shell and Noctalia. [SHELLS](https://github.com/metaspartan/kwickos/blob/main/docs/SHELLS.md)
* **Quick Look, Capture, Clipboard history and the Control Center** on the desktop, a dock that stays put when apps open, and image and video thumbnails in Files.
* **Upgrades from older installs**: `apt upgrade` brings in the new kinit, kpkg and release files through `kwick-core`, and the new shell tools through `kwick-update`.
