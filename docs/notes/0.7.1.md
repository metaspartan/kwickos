## New in 0.7.1

0.7.1 is the first public release after 0.6.5 and includes everything planned for 0.7.0.

**Local AI and agents**
* **Local Models**: `kwick-agents inference` installs a verified llama.cpp build chosen for your GPU (CUDA, Vulkan, ROCm or CPU), offers pinned models with a fit check before download, and runs one keyed OpenAI- and Anthropic-compatible endpoint on `127.0.0.1:11435`, off by default. Cybara, opencode, Codex, Goose, Hermes, OpenClaw and oh-my-pi connect to it automatically. Settings > Agents > Local Models and a Local AI section in Software. [INFERENCE](https://github.com/metaspartan/kwickos/blob/main/docs/INFERENCE.md)
* **Agents that use the desktop**: kwick-mcp reads and changes 57 settings and offers computer use (screen, pointer, keyboard, windows, clipboard) behind a consent dialog, with an on-screen control capsule, a Stop button, Meta+Alt+Escape, protected password and system windows, rate limits and an audit log. Cybara is listed first and its built-in computer use goes through the same safeguards. [AGENTS](https://github.com/metaspartan/kwickos/blob/main/docs/AGENTS.md)
* Coding agents (Claude Code, Codex, Gemini CLI, opencode, oh-my-pi, OpenClaw, Hermes, Goose and more), pinned, verified and sandboxed, with keys in KWallet or GNOME Keyring.

**Desktop**
* **Appearance**: the macOS layout defaults to an orange accent; 17 accents and a custom colour, a separate highlight colour, neutral or accent sidebar icons, and wallpaper tinting with translucent sidebars.
* **macOS styling** for KDE, GTK and GNOME apps: switches, accent default buttons, segmented tabs, menus, tooltips, toolbars and settings dialogs.
* **Keyboard shortcuts**: one keymap for Plasma, GNOME, Hyprland and sway, Settings > Keyboard to rebind, and a searchable cheat sheet (Cmd+/ in the macOS layout, Meta+K elsewhere). [KEYS](https://github.com/metaspartan/kwickos/blob/main/docs/KEYS.md)
* **Snapshots**: Btrfs snapshots around every software change and every hour, file restore, rollback, and booting a snapshot. [SNAPSHOTS](https://github.com/metaspartan/kwickos/blob/main/docs/SNAPSHOTS.md)
* **Updates**: KwickOS, app and kernel updates in one place, kernels that start once before becoming the default, and a Debian security tracker check. [UPDATES](https://github.com/metaspartan/kwickos/blob/main/docs/UPDATES.md)
* **Software**: Flathub, Debian, AI agents, local models, and Arch and the AUR once turned on.
* **Send Nearby**: send files to phones and computers nearby, compatible with LocalSend. [NEARBY](https://github.com/metaspartan/kwickos/blob/main/docs/NEARBY.md)
* **Search**, **Glance**, **Capture**, clipboard history, **Quick Settings** and **Notifications**; shell switching for terminals and desktop shells; a crisp new K logo.

**Headless**
* Smaller than Alpine Linux 3.24 in every measured way: base image, live ISOs on amd64, arm64 and riscv64, boot time, memory after boot, and installed size with curl, python3, git, nginx and openssh-server, through new lean musl builds that `apt install` picks on headless systems (`--no-lean` gives Debian's). [BENCHMARKS](https://github.com/metaspartan/kwickos/blob/main/docs/BENCHMARKS.md)
* kinit runs systemd timers (logrotate, fstrim, certbot renewals), serves its control socket without blocking, and honours unit aliases; kpkg loads its index several times faster, refuses apk/dpkg file conflicts and unverified packages, and honours dpkg path-exclude.

**Security**
* Releases now wait for the security check: kernel, Go modules, the container image, BusyBox, agent lock files and every lean-build source are scanned.
* BusyBox `wget` refuses HTTPS it can't verify; Arch and AUR installs run unprivileged in a user namespace; Send Nearby's contacts-only mode trusts only TLS client certificates; CI actions are pinned and least-privilege; kernel sources are signature-checked.

**Upgrading**
* `apt update && apt upgrade` (or Updates) moves 0.6.x installs to 0.7.1, including desktops installed from the ISO, which now receive desktop updates. Your settings are kept.
