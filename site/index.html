KwickOS

Tiny, fast, Debian 13 compatible Linux for every architecture.

A 5.5 MB base that installs software like Debian, with an optional desktop that looks like macOS, Windows 11 or a Linux shell at the flip of a switch.

The desktop

Three layouts.
One command.

kwick-layout macos|windows|linux switches the whole look at once: window buttons, panel or dock position, fonts, icons, wallpaper and the Files sidebar. Every layout is dark.

KDE Plasma, macOS layout

macOS

The default. A full-width menu bar with a white KwickOS mark and a compact clock, a floating dock with 48 px icons, and traffic-light buttons at the top left of every window.

Windows 11

A 48 px centered taskbar with the KwickOS start icon, a small padded clock and Fluent caption buttons on the right.

Linux

A thin top bar with launcher, centered clock and tray, and a floating dock on the left.

KDE, GNOME and Hyprland

Your desktop.
Same layouts.

KDE Plasma 6 is the default. The same three layouts apply to GNOME and to Hyprland, which comes with a waybar per layout through the kwick-hyprland package.

Other desktops install with kwick-desktop install xfce|cinnamon|mate|lxqt and are chosen with kwick-desktop switch.

Kwick Effects

Motion with
personality.

Native effects that run as KWin effects on KDE, GNOME Shell extensions on GNOME and animations on Hyprland. Pick a preset with kwick-effects off|subtle|fluid|full, or switch them one at a time.

  1. offNo animations.
  2. subtleFades, blur, sliding popups, magic lamp.
  3. fluidPlus curvy wobbly windows, sheets and the 3D flip open and close.
  4. fullPlus flame open and close, translucency, dimmed inactive windows, the lit 3D desktop cube and Cover Flow Alt+Tab.

Captured in a KVM guest with a virgl GPU. The capture path drops frames, so the GIFs are jumpier than the real thing. Effects need a GPU compositor.

KwickOS Settings

Everything,
one place.

kwick-settings has pages for Appearance (layout and accent color), Dock, Effects, Fonts, Desktop Session, GPU and Gaming. It tells you when no GPU compositor is running and offers to install kwick-gpu.

Gaming

Native Steam.

steam enables the i386 architecture through kpkg multiarch, installs Debian’s steam-installer, downloads the client and runs it. If the native install fails, it falls back to the Flathub build.

kwick-gaming adds Proton-GE, Heroic, Lutris, GameMode and MangoHud from Flathub, with a gaming sysctl preset.

GPU support

Drivers, detected.

apt install kwick-gpu detects your GPUs and installs the matching drivers and firmware. It also runs after apt install kwick-desktop, and kwick-gpu alone shows the plan.

AMD and Intel

In-kernel amdgpu, i915 and xe with Mesa (RADV, radeonsi, iris, ANV) and firmware.

NVIDIA Turing and newer

NVIDIA open kernel modules, pinned, plus userspace from NVIDIA’s Debian 13 repository. Older cards use nouveau with Mesa NVK.

Apple Silicon

The Asahi kernel variant, kwick-kernel-asahi, with Mesa asahi and honeykrisp.

Virtual machines

virtio, QXL, Bochs, VMware and Hyper-V through in-tree DRM drivers with Mesa virgl or llvmpipe.

Every kernel flavor ships a matching headers package for DKMS. What was run on real hardware and what was only built is listed per entry in docs/HARDWARE.md.

apt and Debian compatibility

Small like Alpine.
Installs like Debian.

apt install runs against the unmodified Debian 13 “trixie” archive, about 69,000 packages with glibc pulled in only when something needs it.

$ docker run --rm -it ghcr.io/metaspartan/kwickos
root@kwick:/# apt update && apt install -y nginx python3
root@kwick:/# systemctl enable --now nginx

kpkg

An apt and dpkg compatible package manager that uses Debian’s own repositories, with multiarch for foreign architectures.

kinit

A 120 KB PID 1 that runs systemd unit files, so apt install nginx gets you a running, enabled, supervised service.

No boot chain

The kernel is a UEFI app with an embedded root finder. Kernel updates copy one EFI file and keep the previous one for rollback.

Essential, virtually

BusyBox satisfies the Debian Essential packages, so real Debian packages install unmodified on a 5 MB system.

Self-healing

If a maintainer script trips over a BusyBox difference, kpkg installs the GNU tool from Debian and retries.

Every architecture

Signed apt repository

Already running
KwickOS?

This site is the signed apt repository for KwickOS kernels and the desktop edition. The repository is preconfigured. Upgrade to the desktop edition with:

Desktop edition
apt update && apt install kwick-desktop

Manual setup:

Add the repository
curl -fsSL https://metaspartan.github.io/kwickos/kwickos-archive-keyring.asc -o /usr/share/keyrings/kwickos-archive-keyring.asc
printf 'Types: deb\nURIs: https://metaspartan.github.io/kwickos\nSuites: stable\nComponents: main\nSigned-By: /usr/share/keyrings/kwickos-archive-keyring.asc\n' > /etc/apt/sources.list.d/kwickos.sources

Kernel updates arrive with apt update && apt upgrade. kwick-kernel-install --list | --rollback manages kernels.
