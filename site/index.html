KwickOS

A smaller base than Alpine. Installs like Debian.

A 6.6 MB Linux base for every architecture. apt pulls straight from Debian 13, Alpine’s apk works right next to it, and an optional desktop looks like macOS, Windows 11 or a Linux shell at the flip of a switch.

The desktop

Three layouts.
One command.

kwick-layout macos|windows|linux switches the whole look at once: window buttons, panel or dock position, fonts, icons, wallpaper and the Files sidebar. Every layout comes in dark, the default, and light.

KDE Plasma, macOS layout

macOS

The default. A full-width menu bar with a white KwickOS mark and a compact clock, a floating dock with 48 px icons, traffic-light buttons at the top left of every window and Apple’s orange accent.

Windows 11

A 48 px centered taskbar with the KwickOS start icon, a small padded clock and Fluent caption buttons on the right.

Linux

A thin top bar with launcher, centered clock and tray, and a full-height dock panel on the left.

KDE, GNOME and Hyprland

Your desktop.
Same layouts.

KDE Plasma 6 is the default. The same three layouts apply to GNOME and to Hyprland, which comes with a waybar per layout through the kwick-hyprland package.

Other desktops install with kwick-desktop install xfce|cinnamon|mate|lxqt and are chosen with kwick-desktop switch.

Agents and local models

Local AI.
Wired in.

kwick-agents installs coding agents pinned and verified, starts each one in a bubblewrap sandbox and gives it permissioned access to KwickOS through the kwick-mcp server. Local Models runs open models on your own GPU.

Local Models

llama.cpp built for the GPU in this machine, with the CUDA, Vulkan or CPU build picked for you. Curated, sha256-pinned models come with a verdict on whether they fit your GPU memory, and downloads show their progress and resume.

  • One local endpoint. OpenAI and Anthropic compatible at 127.0.0.1:11435, with the model name local.
  • Agents wired up. kwick-agents inference connect --all points Cybara, opencode, Codex, Goose, Hermes, OpenClaw and oh-my-pi at it. The key stays in the keystore.
  • Off until you ask. The server runs sandboxed and is off by default. Settings and the App Store manage it.

Agents that use the desktop

Through kwick-mcp an agent can read and change 57 settings and use the computer like a person: pointer, keyboard, windows and clipboard. Cybara’s own computer use goes through the same checks.

  • Consent first. The first request asks you: Allow once, Always allow or Deny.
  • Always visible. A capsule at the top of every screen names the agent in control with a Stop button. Meta+Alt+Escape stops every session.
  • Kept out. Password prompts, the lock screen and KwickOS Settings stay out of reach, and every action goes to an audit log.

Pinned and verified

Cybara, Claude Code, Codex, Gemini CLI, opencode, Goose, Aider and more, each pinned to a release and checked against a sha256, a lock file or a git commit.

Sandboxed

Every agent starts in bubblewrap and sees only its own configuration and the project folder it was started in.

Keys in the keystore

API keys live in KWallet or GNOME Keyring and reach an agent only as environment variables when it starts.

Kwick Effects

Motion with
personality.

Native effects that run as KWin effects on KDE, GNOME Shell extensions on GNOME and animations on Hyprland. Pick a preset with kwick-effects off|subtle|fluid|full, or switch them one at a time. Windows can open and close with over thirty animations, among them every Burn My Windows effect, picked in Settings or with kwick-effects open-close.

  1. offNo animations.
  2. subtleScale open and close, blur, sliding popups, magic lamp.
  3. fluidPlus curvy wobbly windows, sheets and the 3D flip open and close.
  4. fullPlus flame open and close, translucency, dimmed inactive windows, the lit 3D desktop cube and Cover Flow Alt+Tab.

Captured in a KVM guest with a virgl GPU. The window effects were slowed down so every frame is a real render, the cube is sampled at fixed points of its animation, and the frames are played back at a steady rate, so the real effects run faster and smoother. Effects need a GPU compositor.

KwickOS Settings

Everything, one place.

kwick-settings has pages for Appearance, Dock, Effects, Fonts, Keyboard, Desktop Session, Shells, GPU, Gaming, Nearby Share, Agents, Local Models, Privacy & Security, Snapshots and Software Update.

Appearance picks the layout, light or dark, the window corner radius and the accent color. The macOS layout uses Apple’s orange, and a color you choose applies to KDE, GTK, GNOME, Hyprland and sway alike.

Keyboard shortcuts

One keymap.
Every desktop.

Change a shortcut in Settings > Keyboard or with kwick-keys set and it works right away in Plasma, GNOME, Hyprland and sway. Meta+K opens a searchable cheat sheet, Cmd+/ in the macOS layout.

Built-in apps

Everyday tools.
Already there.

An App Store, Software Update, Snapshots, Quick Look, Capture and Nearby Share come with the desktop. They follow the layout, the accent color and the light or dark appearance.

Gaming

Native Steam.

steam enables the i386 architecture through kpkg multiarch, installs Debian’s steam-installer, downloads the client and runs it. If the native install fails, it falls back to the Flathub build.

kwick-gaming adds Proton-GE, Heroic, Lutris, GameMode and MangoHud from Flathub, with a gaming sysctl preset.

GPU support

Drivers, detected.

apt install kwick-gpu detects your GPUs and installs the matching drivers and firmware. It also runs after apt install kwick-desktop, and kwick-gpu alone shows the plan.

AMD and Intel

In-kernel amdgpu, i915 and xe with Mesa (RADV, radeonsi, iris, ANV) and firmware.

NVIDIA Turing and newer

NVIDIA open kernel modules, pinned, plus userspace from NVIDIA’s Debian 13 repository. Older cards use nouveau with Mesa NVK.

Apple Silicon

The Asahi kernel variant, kwick-kernel-asahi, with Mesa asahi and honeykrisp.

Virtual machines

virtio, QXL, Bochs, VMware and Hyper-V through in-tree DRM drivers with Mesa virgl or llvmpipe.

Every kernel flavor ships a matching headers package for DKMS. What was run on real hardware and what was only built is listed per entry in docs/HARDWARE.md.

Debian and Alpine compatibility

Debian’s packages.
Alpine’s too.

apt install runs against the unmodified Debian 13 “trixie” archive, about 69,000 packages with glibc pulled in only when something needs it. apk add works alongside it, with a signature-verified bootstrap, so Alpine’s musl packages and Debian’s glibc packages live side by side.

$ docker run --rm -it ghcr.io/metaspartan/kwickos
root@kwick:/# apt update && apt install -y nginx python3
root@kwick:/# systemctl enable --now nginx
root@kwick:/# apk add nodejs

kpkg

An apt and dpkg compatible package manager that uses Debian’s own repositories, with multiarch for foreign architectures.

kinit

A 130 KB PID 1 that runs systemd unit files, so apt install nginx gets you a running, enabled, supervised service.

No boot chain

The kernel is a UEFI app with an embedded root finder. Kernel updates copy one EFI file and keep the previous one for rollback.

Essential, virtually

BusyBox satisfies the Debian Essential packages, so real Debian packages install unmodified on a 6.6 MB base.

Self-healing

If a maintainer script trips over a BusyBox difference, kpkg installs the GNU tool from Debian and retries.

31 of 31 pass

PostgreSQL 17, MariaDB 11.8, Docker, OpenJDK 21, Go, gcc, Node.js, Python, PHP, Ruby, Redis, nginx, Apache, OpenSSH and more.

VPN built in

WireGuard in the kernel, OpenVPN, OpenConnect, IPsec and L2TP in every desktop session, plus kwick-vpn to import profiles and add Tailscale, Mullvad, Proton, ZeroTier or NetBird.

NAS ready

Prebuilt OpenZFS modules for every KwickOS kernel, a mergerfs and SnapRAID parity array, SMB and NFS shares, iSCSI, SMART, UPS, Docker and VMs, managed from Cockpit or kwick-storage.

kfetch

A 10 KB system summary in plain shell on both editions, with the K logo, GPU, packages, init, disk and IP. kfetch --json and --small included, about 15 ms.

Size and speed

Smaller base than Alpine.
Boots faster than Alpine.

KwickOS 0.7.0 measured against Alpine 3.24.4, Debian 13 slim and Ubuntu 26.04 on one machine, amd64. Where Alpine is ahead, the table says so.

KwickOS wins on the base: image size, boot time, memory, and the whole Debian archive with glibc. With KwickOS’s lean musl builds it also ends up smaller than Alpine after installing curl, python3 or git, and narrowly (0.2–0.5 MB) with nginx or openssh-server; with Debian’s own packages Alpine stays several times smaller, and Alpine’s base gets dedicated security maintenance. The KwickOS base ships no TLS library; Alpine’s includes OpenSSL and CA certificates. KwickOS is VM- and container-first, with limited real-hardware testing so far. Method, raw output and the full results are in docs/BENCHMARKS.md.

Signed apt repository

Already running
KwickOS?

This site is the signed apt repository for KwickOS kernels and the desktop edition. The repository is preconfigured. Upgrade to the desktop edition with:

Desktop edition
apt update && apt install kwick-desktop

Manual setup:

Add the repository
wget -qO /usr/share/keyrings/kwickos-archive-keyring.asc https://metaspartan.github.io/kwickos/kwickos-archive-keyring.asc
printf 'Types: deb\nURIs: https://metaspartan.github.io/kwickos\nSuites: stable\nComponents: main\nSigned-By: /usr/share/keyrings/kwickos-archive-keyring.asc\n' > /etc/apt/sources.list.d/kwickos.sources

Kernel updates arrive with apt update && apt upgrade. kwick-kernel-install --list | --rollback manages kernels.
